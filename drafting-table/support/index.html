Privacy policy

Getting help

Email work@justice.engineering and I'll get back to you. It helps a lot if you include the app version (shown in Drafting Table ▸ About Drafting Table) and your macOS version ( ▸ About This Mac).

The fastest way to report a problem is from inside the app: Help ▸ Send Feedback opens a pre-filled report email with the version details already included.

Reporting a bug

For bug reports, please include:

  • What you were doing when it happened, step by step if you can
  • What you expected, and what happened instead
  • The app version and macOS version
  • If it involves a specific document, the .plansheet file (or a screenshot) if you're comfortable sharing it

Frequently asked questions

Where are my documents stored?

Wherever you save them. Drafting Table documents are normal .plansheet files on your disk — there's no hidden library or cloud copy. Move them, back them up, and organize them like any other file.

Does it need an internet connection?

No, never. Drafting Table works entirely offline.
